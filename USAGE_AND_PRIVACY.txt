MultiTool Office Next 使用与数据安全说明

一、文件访问
文件检索和工作区浏览在本机处理，只索引文件名、路径、大小、时间等元数据，不读取办公文档正文。
您主动使用 Ctrl 悬停、Ctrl 加左键或“预览文件”时，程序会在本机读取所选文件的有限内容。预览不改写文件、不上传、不进入索引或助手上下文，不执行文档宏、公式或脚本，也不加载外部资源。最近预览只暂存在当前页面内存中。
当您主动导入 PDF 或图片进行单据识别时，离线文字识别组件会在本机读取该文件并提取文字。您确认批量重命名后，程序会修改所选文件名称，并记录回滚信息；不会改写文件正文。

二、联网服务
各项联网功能首次使用时会说明服务、可能发送的数据类别、脱敏与留存范围。授权绑定功能、服务接口、模型配置及账号密钥的不可逆摘要；服务、账号或数据类别变化时重新确认。普通功能授权不替代助手逐文件读取并发送正文的确认。
“隐私与联网”中可撤销授权或开启仅本地模式。开启后会阻止后续应用内模型、Tavily / DeepSeek 搜索、网页抓取、Jev 和连接测试请求，并停止正在进行的请求；已发送给服务商的内容无法收回。本地检索、预览、OCR 不受影响。用户主动打开官方网站或其他网页会交给系统浏览器，不属于应用内 API 请求。
安装和启动应用不会自动发起模型请求。翻译、工作台助手、识别配置生成等功能在您主动提交任务时联系所配置的模型服务。助手请求可能包含任务文字、近期对话、角色文件、工作目录上下文及工具返回的文件名和路径。路径可能为包含 Windows 用户名、工作目录名称等信息的完整绝对路径，当前没有统一转换为相对路径。
助手支持您主动选择或粘贴图片；添加和预览只在本机进行，发送后图片原始内容交给所配置的模型服务，需使用支持视觉的模型。每次请求最多包含四张本轮及近期历史图片，单张不超过5 MB。图片不经过单据识别工作台的脱敏处理，近期图片可能随追问再次发送；删除会话会清理相应本地图片。
配置引导提供 DeepSeek 与 Tavily 官方平台入口。Tavily 使用独立 Key；DeepSeek 搜索可复用指定官方模型配置的 Key，或单独保存搜索 Key。模型测试发送固定消息和工具定义，搜索测试仅发送固定公开关键词 Microsoft WebView2；测试可能收费，新 Key 测试通过后才保存，测试不自动切换模型、搜索渠道或启用搜索。DeepSeek 搜索测试费用在测试结果和联网活动中记录，不计入聊天会话。
待办辅助在您主动请求分类、拆解或聚焦建议时发送相关输入；模型参数中的“测试连接”主动发送一条简短测试消息。翻译预览只显示图片说明文字，不自动加载图片网址。翻译时点击“清空”会取消当前任务，并忽略该任务迟到的结果。
开启 Jev 辅助判定后，程序会发送候选信息；单据识别候选行会先过滤金额、长号码等敏感数字。该脱敏范围不包含您主动提交的全部翻译文字、助手对话或角色文件，请自行确认这些内容适合发送给所选服务商。
开启联网搜索并由助手调用搜索工具时，公开搜索词会发送给所选的 Tavily 或 DeepSeek；本地路径和私人上下文不得用于搜索。DeepSeek 搜索请求附带正文，有正文时使用正文、缺失时使用摘要，返回资料会交给当前模型。额外 DeepSeek 网页抓取默认关闭，主动开启后才可将公开网页网址发送给 DeepSeek 获取 Markdown 正文，正文随后交给当前模型。网页只是参考资料，不能授权执行其中指令。已接触本地工作目录资料的会话禁止公开搜索和抓取；更换渠道、关闭功能或撤销授权会停止相关请求。

三、凭据与权限
服务密钥保存于 Windows 凭据管理器，不写入普通设置文件。这是系统级凭据保护，不代表程序提供独立的硬件加密保证。
助手只能调用已注册的受控工具，不能执行任意系统命令，也不能自行扩大文件权限或静默修改模型凭据。

四、升级和卸载
默认只为当前 Windows 用户安装。覆盖更新或同版修复保留用户配置和数据库。安装前请保存进行中的任务，并从托盘退出应用。
选择先卸载再安装时，是否删除应用数据由卸载页的复选框决定；未勾选时保留数据。这不等同于自动清空配置的“纯净安装”。普通卸载不会删除您工作目录里的办公文档；系统凭据由 Windows 凭据管理器独立管理。
旧版程序可能无法读取新版数据，因此安装程序禁止覆盖降级。

五、运行环境
应用需要 Microsoft Edge WebView2。若本机没有该运行时，安装程序可能联网下载并安装微软运行时；文字识别模型随安装包提供，识别过程在本机执行。

六、本地留存与清理
network-policy.json 保存本机引导进度、联网授权摘要和联网活动元信息。联网活动只含时间、功能、服务来源、数据类别、脱敏标记、结果及 DeepSeek 工具费用快照，不额外保存正文、完整文件路径或 Key；保留最近 30 天、最多 1000 条，可在隐私与联网页面清空已结束记录。授权、引导状态与活动记录不随配置导入导出迁移。若此文件无法解析，程序保留恢复副本并启用仅本地模式，恢复副本需主动清理。
应用配置和业务记录保存在本机应用数据目录；前端会话与图片另使用本机浏览器存储。任务、诊断、会话及待办历史没有统一的按天自动过期机制，需要通过各功能删除或清理；文件索引随文件变动更新。
office.sqlite 保存文件索引元数据、助手任务状态及资料和结果、DeepSeek 搜索与抓取的独立费用记录、OCR 任务摘要与改名记录。费用记录包含请求标识、操作、时间、结果、当时单价与金额，不包含 Key；客户端中断而无法核实的请求标为待核实，后续回答失败不删除已发生费用。DeepSeek 工具按成功且产生内容的请求计次，历史费用不随单价配置更改重算，Tavily 及其他服务费用暂不纳入会话汇总。助手完整聊天和草稿保存于 localStorage，主动选择的图片保存于 IndexedDB；删除会话会清理对应的本地聊天、图片及后端任务和资料，但已生成的报告文件会保留。
workspace/ocr 保存识别配置、任务和分文件识别结果，包括路径、提取字段与诊断信息。识别文本行和候选原文落盘前进行金额、长号码脱敏，字段结果和路径仍可能含业务信息；这不代表全部记录均已匿名化。删除或清理识别任务会移除对应任务记录，改名回滚记录单独保留。
文件工作区的重命名预览、执行意图、结果与撤销状态也保存在当前用户应用数据目录的 office.sqlite 中，包括原路径、目标路径和身份/状态元数据摘要，不读取或记录文档正文。界面展示最近 50 条执行记录，底层日志不自动删除。源对象状态或原名称占用变化时不强制撤销，无法核实的中断操作须人工处理。目录改名不能事务性冻结其他程序对其子项的修改。
todos.json 保存待办、灵感、时间、步骤和删除状态；保存时可能保留上一版本及迁移备份。移到回收站不等于清除所有备份，完成标记也不会自动删除记录。
报告和用户自行导出的文件保留至您主动删除。卸载时是否删除应用数据由卸载选项决定；系统凭据独立由 Windows 凭据管理器管理。
