# v0.4.0 调整与验收清单

v0.5.0 的 OCR 一键任务 / 自动配置、跨层目录筛选、快捷面板最近访问，参见 [issues #9–#12 实现与人工验收](issues-9-12.md)。这些改动不计入下方 v0.4.0 的既有验收结论。

发布日期：2026-10-19；应用构建版本：`2026.1019.2128`。正式变化见[变更日志](../CHANGELOG.md)。

本地文件整理为基础，AI 与联网搜索按需配置；使用外部服务时清楚说明数据范围。

## 本版变化

- AI 助手增加 PDF 创建与预览，修复交付链接权限判断、收起后的文件确认、任务续接和应用中断恢复。
- 完善等待预算、上下文压缩与流式异常提示，保留完整本地记录和已完成的文件。
- 增加 Windows 文件拖出及 `Alt+1` 至 `Alt+5` 模块切换，调整常用工具设置的字段对齐与操作布局。

- 首次启动引导添加工作目录、配置模型和配置搜索，各步骤可稍后继续；顶栏和设置提供重新打开入口。
- 新模型配置提供 DeepSeek 推荐参数、官方 Key 获取步骤；保留原有模型和自定义兼容接口。
- 新增 DeepSeek 搜索渠道，保留 Tavily；可复用指定 DeepSeek 模型 Key 或单独填写。搜索有正文则使用正文，额外 Fetch 默认关闭。
- 搜索测试只发送固定公开关键词，新 Key 测试成功后才保存；测试和启用搜索分开操作。
- DeepSeek Search / Fetch 按次费用独立记录并纳入会话费用，保留请求时单价；测试费用在联网活动中查看。详见[配置与费用验收清单](deepseek-search.md)。
- 各项联网功能首次确认服务与数据范围；换服务或账号、授权范围扩大后重新确认。助手逐文件读取授权继续保留。
- “隐私与联网”提供授权撤销、仅本地模式与活动摘要。仅本地模式也阻止连接测试；关闭搜索后，后台任务不能继续搜索或抓取。
- 活动仅记录时间、功能、服务、数据类别、脱敏状态、结果及 DeepSeek 工具费用快照，保留最近 30 天、最多 1000 条，不额外保存正文、完整路径或 Key。配置导出不含授权、活动及引导进度。
- OCR 逐项预检，显示名称修正与重名序号；异常项可排除。执行和撤销明确统计成功、失败、未处理及排除项目。
- 支持识别失败、中断、待复核筛选，单项重试和异常 CSV 导出；撤销失败可再次尝试。
- 兼容原有 OCR 配置、任务与改名记录，不新增模板；保留身份检查、不覆盖文件及中断恢复机制。
- WebView2 下载与安装失败时提供中文恢复说明和微软官方页面。

## 开发检查

默认只做静态检查与构建，不自动连接真实服务、不启动应用读取业务资料，也不运行模拟测试。

```powershell
npm.cmd run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows.ps1 -Action check
node scripts/check-installer.mjs
```

本轮在用户明确授权后运行隔离验证：21 项桌面流程、6 项 PI 调度检查、39 项 Rust 单元测试通过，另有 2 项离线 OCR／本地记录重放用例保持忽略；前端构建、模型设置与计价检查通过。桌面验证使用独立数据目录、虚构文件和本机回环模拟接口，不调用真实付费模型。PDF 另经文字提取与页面渲染核对，确认中文正文和表格存在。

正式安装包完成版本与 SHA-256 核验，并由用户进行实际测试。仓库未配置 GitHub Actions 工作流，本次不宣称已通过云端 CI，也不据此宣称下列所有人工场景均已逐项验收。

## 由用户操作的验收清单

- [ ] 首次引导能打开两家官方平台，分别说明用途、Key 获取方法与费用；跳过后可以继续配置。
- [ ] 模型连接测试成功后才能启用；换入无效 Key 不破坏原有效配置。
- [ ] Tavily 测试与启用分开；仅配置搜索时，界面仍明确提示模型未配置。
- [ ] 首次使用联网功能会确认服务与范围；拒绝后不发送，后续可重新操作。
- [ ] 仅本地模式下模型、翻译、待办辅助、AI 配置、Tavily / DeepSeek 搜索、网页抓取、Jev 和连接测试均不能外发；本地功能可继续使用。
- [ ] 撤销授权或关闭搜索后，正在进行的请求会停止，后续请求不能沿用旧授权。
- [ ] 活动详情只含类别、结果及 DeepSeek 工具费用快照；清空前需要确认，聊天、业务任务和报告不会因此被删除。
- [ ] 使用用户自行选定的文件副本，核对 OCR 单项失败、文件变化、重名和长路径的逐项提示。
- [ ] 部分改名成功时，统计与实际文件一致；只重试失败项，不重复处理成功文件。
- [ ] 撤销遇到占用或原名冲突时，保留未撤销记录；解决问题后可以再次撤销。
- [ ] 异常 CSV 包含状态和原因；升级能继续查看旧任务与改名记录。
- [ ] 在用户自行准备的安装环境中核对 WebView2 缺失、下载失败、安装失败提示及官方入口。

尚未据此宣称 OCR 准确率、真实服务连接或全新安装环境已经验证。
