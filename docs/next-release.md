# 下一版调整（待发布）

本地文件整理为基础，AI 与联网搜索按需配置；使用外部服务时清楚说明数据范围。

## 本版变化

- 首次启动引导添加工作目录、配置模型和配置搜索，各步骤可稍后继续；顶栏和设置提供重新打开入口。
- 新模型配置提供 DeepSeek 推荐参数、官方 Key 获取步骤；保留原有模型和自定义兼容接口。
- Tavily 独立测试只发送固定公开关键词，新 Key 测试成功后才保存；测试和启用搜索分开操作。
- 各项联网功能首次确认服务与数据范围；换服务或账号、授权范围扩大后重新确认。助手逐文件读取授权继续保留。
- “隐私与联网”提供授权撤销、仅本地模式与活动摘要。仅本地模式也阻止连接测试；关闭 Tavily 后，后台任务不能继续搜索。
- 活动仅记录时间、功能、服务、数据类别、脱敏状态和结果，保留最近 30 天、最多 1000 条，不额外保存正文、完整路径或 Key。配置导出不含授权、活动及引导进度。
- OCR 逐项预检，显示名称修正与重名序号；异常项可排除。执行和撤销明确统计成功、失败、未处理及排除项目。
- 支持识别失败、中断、待复核筛选，单项重试和异常 CSV 导出；撤销失败可再次尝试。
- 兼容原有 OCR 配置、任务与改名记录，不新增模板；保留身份检查、不覆盖文件及中断恢复机制。
- WebView2 下载与安装失败时提供中文恢复说明和微软官方页面。

## 开发检查

默认只做静态检查与构建，不自动连接真实服务、不启动应用读取业务资料，也不运行模拟测试。

```powershell
npm.cmd run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows.ps1 -Action check
node scripts/check-installer.mjs
```

原生代码内的回归用例用于保护服务账号绑定、请求类别摘要和 OCR 部分失败/撤销兼容性；本轮仅编译检查，不执行用例。

## 由用户操作的验收清单

- [ ] 首次引导能打开两家官方平台，分别说明用途、Key 获取方法与费用；跳过后可以继续配置。
- [ ] 模型连接测试成功后才能启用；换入无效 Key 不破坏原有效配置。
- [ ] Tavily 测试与启用分开；仅配置搜索时，界面仍明确提示模型未配置。
- [ ] 首次使用联网功能会确认服务与范围；拒绝后不发送，后续可重新操作。
- [ ] 仅本地模式下模型、翻译、待办辅助、AI 配置、Tavily、Jev 和连接测试均不能外发；本地功能可继续使用。
- [ ] 撤销授权或关闭搜索后，正在进行的请求会停止，后续请求不能沿用旧授权。
- [ ] 活动详情只含类别与结果；清空前需要确认，聊天、业务任务和报告不会因此被删除。
- [ ] 使用用户自行选定的文件副本，核对 OCR 单项失败、文件变化、重名和长路径的逐项提示。
- [ ] 部分改名成功时，统计与实际文件一致；只重试失败项，不重复处理成功文件。
- [ ] 撤销遇到占用或原名冲突时，保留未撤销记录；解决问题后可以再次撤销。
- [ ] 异常 CSV 包含状态和原因；升级能继续查看旧任务与改名记录。
- [ ] 在用户自行准备的安装环境中核对 WebView2 缺失、下载失败、安装失败提示及官方入口。

尚未据此宣称 OCR 准确率、真实服务连接或全新安装环境已经验证。
