# 助理文件工作目录与安全边界

默认工作目录为空、文件权限关闭。旧会话目录、本地存储、配置导入和助理提案均不构成文件授权；不自动迁移旧目录为已授权目录。

## 用户流程

1. 在设置中选择本地专用文件夹。只保存位置不会授权文件访问。
2. 勾选允许读取和新建文件后，显示具体目录、当前模型服务及风险说明。用户再次勾选理解风险并确认，原生层才保存权限。
3. 读取单个文件前，确认相对路径、格式和大小，以及正文将发给当前模型服务的事实；生成文件前，确认文件名、格式和内容预览。拒绝、取消、超时都不执行。
4. 可随时撤销授权；换目录或换模型服务后重新确认。撤销不能收回已发送给模型的内容，也不会删除既有文件或聊天记录。
5. 交互 HTML 是独立、默认关闭的附加权限。先完成基本目录授权，再勾选交互网页并二次确认脚本风险；每个文件还需勾选理解风险并确认。取消或超时不改变已有基本权限；撤销基本权限同时关闭交互权限。

## 后端强制边界

- 权限单独保存，不通过普通配置导入、助理提案或角色文件授予。
- 一次性确认令牌绑定目录物理身份、权限版本和模型服务；过期或发生变化后失效。每项读写再次核验当前授权。
- 只允许本地非系统目录；拒绝磁盘根目录、用户个人目录根部、网络路径、系统/应用/凭据目录。
- Windows 文件句柄锁定目录层级，拒绝重解析点、符号链接、目录联接、硬链接和 NTFS 附加数据流；读取验证最终物理路径与文件身份。文件读取允许已有 Office 编辑句柄保持打开，但拒绝删除共享；确认与读取前后核对大小及修改时间，发生变化则停止并要求保存后重新确认。此版本核对不能替代编辑程序的事务快照，处理频繁写入的文件时应先保存并停止编辑。
- 文件预览、定位与打开同时识别文件浏览目录和当前有效的助理工作目录授权；撤销助理授权不会把该目录自动加入文件浏览范围。
- 新配置的任务总等待默认 30 分钟，单次请求默认 10 分钟；已有显式设置保留，可在界面检查调整建议后保存。上下文压缩只处理发送副本中的历史回复和工具资料，不修改本机完整记录，也不截断当前用户要求及原生权限约束。超出容量时最多进行一次更强的压缩重试，仍失败则明确提示；续接任务使用原目标、原目录和已执行记录，成功交付的文件标识保留。
- 仅支持普通 TXT/MD/CSV/JSON/HTML/DOCX/XLSX/PPTX 文件。读取有大小、解压大小和返回文字限制，不执行宏、公式、脚本或外部链接。
- 新增 PDF 创建及交付链接，PDF 正文读取未开放。只接受与普通文档相同的标题、段落和表格，由禁用脚本及外部导航的隐藏 WebView2 渲染受控静态模板，导出 A4 PDF 内存流。确认前不保存临时文件或输出文件，确认后仍由安全目录句柄新建；取消、超时或任务被中断时销毁临时排版窗口。不会调用 Office、外部转换器或加载模型提供的 HTML 源码。
- 已识别的私钥及常见密钥/密码赋值内容禁止发给模型；此识别不可能覆盖所有敏感信息，用户仍须在授权前清理目录和核对单文件。
- 普通文档使用结构化内容与可信模板，Excel 单元格写为文字，静态 HTML 禁止脚本和外部资源。整份 HTML 源码不能塞入静态正文冒充交互网页；返回明确的工具和授权提示。
- `html_app_create` 单独核验交互授权、权限版本、目录身份与模型绑定，仅在本轮要求制作并保存文件时可用。接收不超过 1 MB 的完整源码，避免使用文档段落的 8 KB 上限；只有真实保存并登记后才返回交付链接。
- 交互源码只放入导出文件的 `iframe srcdoc`，仅使用 `sandbox="allow-scripts"`，不开放同源、弹窗、下载、表单提交或顶层导航。受控外层与最先插入的内层 CSP 限制常规网络请求、外部资源、嵌套页面及动态代码求值；权限策略拒绝摄像头、麦克风、定位、剪贴板等能力。应用预览只展示文字，应用本身的 CSP 不放宽，保存后不自动打开或执行。
- 交互导出不是完整代码安全审计，也不是绝对无网络保证。浏览器漏洞、部分网络机制、诱导输入、资源耗尽等仍有残余风险；用户须使用现代浏览器、手动打开、避免输入敏感信息。撤销授权只约束后续助理工具操作，不会停止外部浏览器或改变已保存的副本。
- 文件确认使用独立对话框、固定操作区、可展开的源码预览和倒计时；不依赖长聊天记录中的按钮。事件订阅后补读待确认队列，每三秒恢复遗漏请求；助理收起时仍能显示确认窗口，允许显示其他会话的待确认文件并标记来源。关闭弹窗可重新打开，不能自动确认。文件确认最多五分钟且受任务总预算限制；设置授权的一次性风险确认仍为两分钟。
- 只新建，不开放覆盖、删除、重命名、命令执行或任意路径写入。重名返回失败，用户可换名；所有旧 HTML 报告出口也必须经过目录权限检查。
- 操作记录包含时间、任务、相对文件名、类型和结果；不额外记录正文。操作内容可能保存在聊天/模型服务中，这是授权风险的一部分。
- 接触工作目录文件名或正文后，整个会话标为涉及本地资料，后端禁止继续公开搜索；历史问题、继续任务和新问题不能清除这个标记。公开搜索另建会话。
- 该会话绑定首次读取时的目录物理身份及模型服务。换目录或服务后不能向新服务重放旧会话资料，须新建会话；撤销权限后也不能继续向模型发送这些历史资料。
- 模型绑定还包含接口地址、模型 ID、独立配置 ID 和密钥版本摘要。同一域名的不同配置/账号也不会默认继承授权；不读取或存储密钥正文来计算此摘要。
- 连接版本只由原生保存流程递增，导入不能倒退；切回旧配置也不会自动恢复旧文件授权。
- 一个任务在启动时同时冻结模型设置及密钥；中途更新密钥不能把历史内容或已读正文送入另一个账号。

## 能力范围

生成标准 TXT、DOCX、XLSX、静态 HTML、PPTX、PDF，支持标题、段落、简单表格和标题/要点幻灯片；不提供宏、复杂公式、嵌入对象、联网资源或原文件编辑。单独授权后可导出自包含交互 HTML（内联 CSS/JS、Canvas 等），状态使用内存，不支持 CDN、网络接口、localStorage、cookie、eval/new Function、下载或浏览器 alert。用户请求的源码保持在隔离页面内，不转成正文段落。

隔离策略依据 [MDN iframe sandbox 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox)；`srcdoc` 会继承外层 CSP，多个策略只能继续收紧，见 [W3C CSP3 第 7.8 和 8.1 节](https://www.w3.org/TR/CSP3/#security-inherit-csp)。外层必须允许内联脚本以免继承策略禁用游戏，但外层自身不包含模型代码或脚本。

本边界针对助理工具和目录访问。不能防御与用户相同权限的恶意程序、管理员、用户自行修改权限存储或模型服务已经收到的数据。

## 2026-10-19 流程回归

用户授权后，使用独立 bundle identifier、数据目录和 WebView2 配置，连接仅监听 `127.0.0.1` 的虚构模型服务。测试不加载主界面或生产配置，不读取真实业务文件、账号密钥，不调用付费模型或公开搜索。原生测试会创建并终止自己的测试应用，结果保存在被 Git 忽略的 `test-results/assistant-native-*`。

- `node scripts/check-assistant-flow.mjs`：真实 PI 核心的问答、连续工具、参数拒绝、未知工具、继续轮次和快照恢复。
- `node scripts/check-assistant-native.mjs`：真实 Tauri 命令、原生工具、SQLite、授权确认组件及 WebView2。覆盖六种格式生成、授权目录预览、读取确认/拒绝/文件变化、取消、同名保护、成功文件续接、上下文超限压缩、SSE 异常和多行事件、权限撤销重授及应用关闭恢复。须在具备项目 GNU Rust 工具链的 Windows 环境中、获准模拟测试后手动执行。
- PDF 除文件头外，检查真实输出大小，并用本地 PDF 解析与渲染确认中文正文和表格存在。PDF 页面使用原生内存导航，按导航 ID 等待对应加载完成，避免初始空白页或框架改写 data URL 导致正文截断。
- 任务目标和 PI 调度快照立即落盘；文本流仍节流保存。显式续接只复用当前仍有权访问且确实存在的成功文件。文件交付校验失败保留具体生成错误，文件保护提示不再误导用户更换 API 密钥。

上述模拟验证不等于真实模型兼容性或完整安全审计。真实模型服务、公开搜索、Office 原程序打开，以及更广的文件系统攻击样例未在本轮执行。
