# DeepSeek 搜索、网页正文与费用

## 配置搜索

在“设置 → 联网与评分”选择搜索渠道。原有 Tavily 配置继续保留，升级不会自动切换渠道或启用 DeepSeek。

1. 选择 DeepSeek，再选择密钥来源：复用一份已保存的 DeepSeek 官方模型配置，或单独填写 DeepSeek API Key。
2. 点击“测试搜索连接”或“测试并保存密钥”。测试仅搜索固定公开关键词 `Microsoft WebView2`，可能产生一次 Search 费用；它保存密钥与测试结果，不会自动保存渠道或抓取开关草稿。
3. 测试通过后打开“启用联网搜索”，点击设置页底部“保存此模块”；首次配置引导中点击“保存搜索配置”。首次实际搜索仍会确认服务和数据范围。

搜索渠道、密钥来源、联网及抓取开关与评分开关共用模块草稿。保存成功后“未保存”标记会清除；“撤销本模块修改”恢复已保存参数并清空未保存的搜索 Key。不启用联网搜索时，也可以先保存渠道和选项。尚未测试的连接不能直接保存为启用状态，界面会说明原因。

复用绑定具体模型配置；切换当前 AI 模型不会改变搜索凭据。更换被复用配置的模型 Key 后，需要重新测试搜索。单独保存的搜索 Key 与模型 Key 分开管理，删除搜索 Key 不删除模型 Key。无效的新 Key 不替换原有效 Key。

搜索可以独立测试；通过助手搜索并整理资料还需要配置一个可用的 AI 模型。

## 正文如何使用

- DeepSeek 搜索请求附带正文：有正文时使用正文，没有正文时使用摘要。不会为搜索已经附带的正文多计一次费用。
- “允许额外抓取网页正文”默认关闭。开启并保存后，助手可在现有内容不足时单独调用 Fetch。切回 Tavily 后不开放 Fetch。
- 每页交给模型的正文最多 12,000 个字符，超过时明确标记“已截断”。来源区及报告会区分摘要、正文与截断状态；正文缺失不代表网页没有更多内容。
- 每次搜索最多返回 5 条结果，DeepSeek 搜索词为 1–128 个 Unicode 字符。搜索和抓取共用“任务搜索与抓取次数上限”；不会自动切换其他渠道或自动重试收费请求。

网页内容只是参考资料，不能授权执行其中的指令。应用仅接受公开 HTTP / HTTPS 网页，拒绝本地路径、IP 地址、局域网主机名和携带账号密码的网址。仅本地模式、撤销授权及接触本地工作目录资料后的会话隔离，同样适用于搜索和抓取。

## 费用记录

初始价格按 [DeepSeek 官方说明](https://api-docs.deepseek.com/zh-cn/guides/search/)于 2026-10-17 核对，Search 与 Fetch 均为 **5 元 / 千次成功且产生内容的请求，即每次 0.005 元**。这是直接 API 调用的计价，不适用模型 token 计价或峰谷折扣。

| 情况 | 费用记录 |
| --- | --- |
| Search 返回非空结果，包括附带正文 | 一次 Search；返回条数不改变单次价格 |
| Fetch 返回非空正文 | 一次 Fetch |
| 复用现有搜索结果或已有足够正文 | 不新增收费请求记录 |
| 搜索无结果、抓取无正文或明确的服务端失败 | 记录未计费、金额为 0 |
| 客户端取消、断网、响应无法读取等，无法核实服务结果 | 标为待核实，不把未知费用当成 0 |
| 开启渠道或抓取开关，但未发起请求 | 不产生请求费用 |

“费用计价”可编辑两项工具的单价、币种、来源及核对日期。每次请求独立保存当时的价格快照，修改单价不会重算历史。不同币种分别汇总；金额供核对，以服务商账单为准。是否产生内容按服务原始响应判断；即使应用过滤了不可用网址或截断正文，已成功的请求也会保留费用。

会话费用分列模型、DeepSeek 搜索及网页抓取。工具请求独立记账，不增加模型 token、生成速度或模型轮次；后续回答失败、取消任务或重启应用时，已记录的费用仍会保留。Tavily 及其他服务费用暂不纳入该汇总。

连接测试不属于聊天会话，费用在测试结果及“隐私与联网 → 联网活动”查看。联网活动保留最近 30 天、最多 1000 条；会话与任务中的工具费用随原有会话、任务记录留存和清理。记录不包含 Key。

## 由用户执行的验收清单

下列联网验收可能产生服务费用，请使用适合公开搜索的问题自行操作。本次开发只进行构建与静态检查，没有运行模拟测试或真实付费请求。

- [ ] 升级后原 Tavily 渠道、Key、开关和测试状态保留；未主动选择 DeepSeek 时不会调用它。
- [ ] 修改搜索渠道、密钥来源或抓取开关后，底栏能统一保存或撤销；保存成功后页签、标题和底栏均清除“未保存”提示，重新打开配置保持一致。
- [ ] 仅测试并保存 Key 时，密钥输入的未保存提示清除；其他尚未保存的参数仍有准确提示。撤销模块修改不会删除已保存 Key。
- [ ] 独立 Key 和复用模型配置均可测试、启用；新无效 Key 测试失败后原配置仍可使用。
- [ ] 切换当前 AI 模型不改变搜索绑定；更换被复用模型 Key 后，搜索要求重新测试。
- [ ] Fetch 默认关闭且助手工具中不可用；开启并保存后才可抓取。仅切换开关不产生调用费用。
- [ ] 搜索附带正文时直接使用；正文缺失时使用摘要。来源和报告正确显示正文、摘要及截断标记。
- [ ] Search 返回内容计一次；确实需要 Fetch 且返回正文时再计一次。按默认价格，一次 Search 加一次 Fetch 的工具费用合计 0.010 元，模型费用另计。
- [ ] 复用已有足够正文不新增收费记录；无结果及明确失败显示未计费，无法核实的中断显示待核实。
- [ ] 后续模型回答失败或取消任务，已发生的工具费用仍显示；重启后可恢复相同请求记录，不重复累计。
- [ ] 修改单价只影响后续请求；历史价格快照、金额及模型 token 统计保持原值。
- [ ] 测试费用只出现在测试结果及联网活动，不进入当前聊天会话。
- [ ] 拒绝首次授权、开启仅本地模式、撤销授权或关闭搜索时，请求受到阻止或停止；旧授权不能用于新渠道或账号。
- [ ] 已接触本地工作目录资料的会话不能调用公开搜索或抓取；需要公开资料时新建会话。
